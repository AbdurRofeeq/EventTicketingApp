Event Ticketing System
A personal project built using the Model-View-Controller (MVC) design pattern. This system streamlines the process of event management, ticket sales, and attendee tracking, ensuring a smooth and user-friendly experience for both event organizers and attendees.

Project Description
The Event Ticketing System allows event organizers to:

Create and manage events.
Set up multiple ticket types with pricing and availability.
Track ticket sales and manage attendees efficiently.

For attendees, the system offers:

The ability to search for events.
View ticket types and purchase tickets.
Receive event details and confirmation after successful purchase.

This project follows the MVC architecture, separating the application logic into Model, View, and Controller layers, ensuring better maintainability and scalability.

Features
Event Creation: Event organizers can create events, define details (title, description, date, time, venue), and set ticket types with pricing and quantity.
Ticket Management: Organizers can manage ticket availability and monitor sales.
Attendee Experience: Attendees can browse events, view available tickets, and complete purchases.
Secure Payment Integration: Implemented for seamless ticket purchases.
Dynamic Dashboard: Displays event statistics, ticket sales, and attendee details.
Validation & Error Handling: Ensures data integrity and smooth user interaction.

Technologies Used
ASP.NET MVC: Core framework for building the application.
C#: Backend logic implementation.
Entity Framework: Database management and CRUD operations.
SQL Server: Relational database for storing event, ticket, and user data.
HTML, CSS, Bootstrap: Frontend for designing user-friendly interfaces.
